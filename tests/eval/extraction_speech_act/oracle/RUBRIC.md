# 0038 oracle — the rubric. Read this once, then start.

You are deciding, for each stored episode: **what does it assert about the
user's relationship to the action?**

## The four answers

**1 — PERFORMED.** The episode asserts the user *carried the action out* —
either on an occasion, or habitually.

**2 — COMMITTED.** The episode asserts the user *decided on, adopted, or bound
themselves to* the action — **without asserting they did it**. Deciding and
doing are separate acts, and this option exists because the last run had
nowhere to put them.

**3 — REPORTED.** The episode asserts only that something was *said,
instructed, preferred, or noted*. No performance, no commitment.

**4 — AMBIGUOUS.** The episode genuinely supports more than one reading.

## The one principle

**The disposition follows what the episode asserts about the user's relation to
the action. A reporting frame does not change the content it reports.**

"Stated…" can open all three and settles none of them: what matters is what
was stated. A stated *preference* is a preference. A stated *intention* is a
commitment. A stated *practice* is a claim about what the user habitually does.

## What I am deliberately NOT giving you

**The per-verb rulings.** I have written a registry that assigns one of these
three to every verb form in the corpus, and if I showed it to you, you would be
executing my rules rather than testing them. The point of this pass is to find
out whether someone applying the principle independently lands where the
registry lands. **Where you disagree with it, the registry is what gets
re-examined.**

## Using option 4

**Choosing AMBIGUOUS is a finding, not a failure or a cop-out.** The frozen
gate this project already uses treats a flagged-ambiguous item as something to
repair, not as a bad answer. Last run's third option went unused in all 66
items because I never told you that — the ambiguity got forced into a binary
instead, which is part of what went wrong.

## Two disclosures you are owed

**This pass is NOT blind, and is recorded as not blind.** You already know from
the last run that `decided to` was the disputed class. Pretending otherwise
would make the result look stronger than it is. What this pass can establish is
whether the principle, applied independently, reproduces the registry's
rulings — a weaker claim than a blind pass, stated as weaker.

**The pack contains 8 repeated items, and you are not told which.** The last
run's real defect was that your policy on one class changed partway through and
nothing could detect it except a positional accident. Repeats measure that
directly. If you notice one, just answer it as you see it now — a changed
answer is data, not a mistake.

## Practicalities

74 cards, about 15 minutes. Every keypress is saved, so `^C` is safe and
re-running resumes exactly where you stopped. `B` back, `S` skip, `Q` save and
quit, `?` help.
