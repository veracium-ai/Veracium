# A1 evidence-checker terminus — a proposal (dev, 2026-08-24; an ARCHIVE MEMBER since v24 — PACKAGE-R23-1: the v23 claims said this rode the package while it traveled by a side channel that never arrived)

Rounds 15–22 have each returned exactly one finding against the A1
evidence machinery — the last six against one ~100-line checker,
`check_a1_carriers.py` — while every round's verdict has also said: no
design issue, U1–U7 and revised U2 substantively approved, 0025
accepted, the co-owned three-passage interface confirmed. Each finding
was real; we folded each same-day; and we think the ladder (shadow →
site → membership → delimiter → fence grammar → rendering context) has
no natural bottom, because the checker is incrementally re-deriving a
Markdown parser to bind a property that should never have lived in
prose. Two proposals, either or both:

**1. The structural terminus (preferred): make the carrier PRODUCED,
not typed — then retire the parser.** The §4b-i supersession row
becomes a rendered artifact generated from a structured record (the
same produced-not-typed identity pattern this line's own round 17
[R17-1, 2026-08-19] invented for package identity, and which ended that
class permanently there). The checker then compares the record to the
rendered row byte-wise — no Markdown semantics, no fence grammar, no
context classification. We would implement this as the v23→v24 change
if you rule it the terminus; the current parsed-table checker remains
as belt-and-braces.

**2. The process terminus: accept with evidence-maintenance status.**
Since round 22 the repo carries two standing gates: P1 — every evidence
artifact must declare and bind an adversarial mutation matrix
(`test_every_evidence_artifact_declares_a_mutation_matrix`; no
unmutated checker can ship again), and P4 — new closure evidence must
run a named test, never a lexical command. Under those gates, we
propose: A1 is ACCEPTED on its approved design, with any further
checker findings handled as ordinary maintenance under P1's regime
rather than as acceptance-blocking rounds. Your own round-15 framing —
"the A1 design itself is ready" — is the disposition we are asking you
to formalize, on whatever evidence bar you consider its terminus.

If neither proposal is acceptable, a statement of the checker's
remaining threat model (what class of mutant, if closed, ends the
ladder) would let us close it in one round instead of discovering its
edges one seal cycle at a time.
