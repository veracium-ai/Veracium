# Phase 1e/1f — THE FINAL GATE (2026-08-14)

**Fixes landed** (derivational map, compound splitting, object-side initialism,
plus the 1d set). Two candidate predicates, measured over the same 93,342
checkable objects:

| predicate | flag rate | precision (classified sample) | catch classes |
|---|---|---|---|
| **Full** (relation-scoped: stemmed anchors on value-bearing, specifics on idiom) | 1.35% | ~10–13% (6/60 + 2 uncertain) | all classes incl. common-noun fabrication ("gifts"/"jewelry" invented list items) |
| **Specifics-only, ALL relations** (numerals, identifiers, proper-noun runs) | **0.47%** | **~40–50%** (6–8/15) | the value-shaped classes — the ones that damage functional facts |

**The 60-flag classification (full mode):** ~10% candidate-true · ~10% my-tool
artifacts (derivational gaps comply/compliance-class, time-format, "not
specified" idiom, cross-lingual translation — each enumerable and fixable) ·
~73% irreducible distiller summary-vocabulary ("service", "module", "options",
"including" — the lexical floor for a compressing distiller).

**New true-catch classes surfaced at the gate** (beyond wrong-value /
cross-window / fabricated-specifics from earlier rounds):
- **Answered-question-as-fact**: user asks "what was the EBITDA margin?" →
  the distiller stores `prefers: 43%` — a VALUE the window never contains.
- **Computed-value-as-testimony**: `budgeted_direct_cost: 13260` — an
  arithmetic SUM of window numbers, synthesized and stored as fact.
- **Added-year**: "Halloween Party **2023**", "April 1st, **2023**" — years
  attached to events with no year in the window (the news-claim-year class,
  now seen 3×).
- **Anticipatory generation**: "create 5 slides" → slide titles stored as the
  user's facts before any slide exists.

## Gate verdict

The instrument is real and the trade is now quantified. **Recommended v1:
the SPECIFICS-ONLY predicate** — 0.47% flag rate at ~40–50% precision, catching
precisely the classes that participate in supersession at full authority
(fabricated values, dates, identifiers), while the full predicate stays an
OFFLINE CORPUS-AUDIT tool (it found real defects in our published artifacts at
~10% precision — useful for auditors, too noisy for a product flag).
