# Generated artifacts

**Not specs.** Files here are produced by a script and verified in CI; they have
no `Spec-Status:` line and cannot be cited in a `Spec:` trailer — the gate fails
closed on a file without a status, which was confirmed by test rather than
assumed.

They live outside the numbered top-level namespace because in `specs/` the
leading number **is** the identity: `0002-audit-manifest.md` sitting next to
`0002-maintenance-provenance-invariant.md` read as a second spec 0002. The
number in the filename here names the spec the artifact *belongs to*, not the
artifact itself.

| file | generated by | verified by |
|---|---|---|
| `0002-audit-manifest.md` | `specs/audit_manifest.py --write` | `--check`, via `test_every_store_mutation_site_carries_a_verdict` |

**Do not hand-edit.** Verdicts for the audit manifest live in
`specs/audit_dispositions.py`.
